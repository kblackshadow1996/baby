# 预置食谱数据说明（data/recipes.json）

本文件是「小饭团成长记」（riceball-grow）官方预置食谱的**数据源**。所有食谱 `isOfficial: true`，由 `cloudfunctions/initRecipes` 云函数导入云数据库 `recipes` 集合。字段结构严格遵循 [`docs/data-model.md`](../docs/data-model.md) 的 `recipes` 集合契约。

## 覆盖范围

| 月龄段 | 阶段（见 `utils/date.js` STAGES） | 食谱数量 |
| --- | --- | --- |
| 0-6 月 | 纯奶期（不加辅食，仅喂养知识卡） | 3 |
| 6-7 月 | 吞咽期（细腻泥糊，单一食材，高铁优先） | 10 |
| 7-8 月 | 蠕嚼期（稠糊带末，蛋黄/肉泥） | 10 |
| 8-10 月 | 细碎期（碎末小块，手指食物引入） | 11 |
| 10-12 月 | 咀嚼期（小块软食，接近家庭饮食） | 10 |
| 12-18 月 | 幼儿期A（三餐规律，接近家常） | 10 |
| 18-24 月 | 幼儿期B（基本同成人，清淡调味） | 10 |
| 24-36 月 | 幼儿期C（均衡饮食，培养自主进食） | 10 |
| **合计** | | **74** |

覆盖 5 个 `type`：`staple`(主食) / `meat`(荤菜) / `veggie`(素菜) / `soup`(汤羹) / `snack`(点心)。

## 数据来源（source.name）

每条食谱均标注权威来源（`source.name` 必填且非空），来源从以下资料中选用并合理分配：

- 《中国居民膳食指南（2022）》中国营养学会
- 《中国婴幼儿喂养指南（2022）》中国营养学会
- 《儿科学（第9版）》人民卫生出版社
- WHO《Complementary Feeding》
- AAP 美国儿科学会辅食添加建议
- 《中华儿科杂志》
- 《中国儿童保健杂志》
- 中国疾控中心《婴幼儿辅食添加营养指南》

> **页码声明**：`source.page` 为**参考占位值**，用于标识引用来源的大致位置，并非精确到行的核实引用。正式发布前需按对应资料的**纸质/官方版本逐条核对**页码与章节。我们不编造精确到行的虚假引用——无法确知的页码一律使用合理占位并在此声明。

## 营养值声明（nutrition）

`nutrition` 字段（`calories` / `protein` / `iron` / `calcium` / `vitamin`）为**每份近似估算值**，基于常见食材营养成分常识估算，用于提供数量级参考，**非精确实验室检测值**。实际数值随食材品种、分量、烹饪方式而变化。相关文本多以「每份约」标注。

## 过敏原标注规则（ingredients.isAllergen / allergens）

常见过敏原类别：**鸡蛋/蛋黄、牛奶、小麦(面)、大豆、花生、坚果、鱼、虾蟹贝类(海鲜)、芝麻**。

- `ingredients[].isAllergen`：该食材若属于上述常见过敏原，置为 `true`，否则 `false`。
- `allergens`：食谱整体含有的过敏原**类别名称数组**（与含过敏原食材对应），无则为空数组 `[]`。
- 食用建议：首次引入高致敏食材（鸡蛋、鱼、海鲜等）应按月龄谨慎、少量尝试，并观察 2-3 天有无过敏反应。

## 喂养科学要点（内容依据）

- 满 6 月龄开始添加辅食，首选**高铁米粉**等富铁食物；由少到多、由稀到稠、由单一到多样。
- 每引入一种新食物观察 2-3 天再添下一种。
- **1 岁内不加盐、不加糖、不加蜂蜜**；1 岁后调味仍以清淡为主。
- 吞咽期(6-7月)细腻泥糊；蠕嚼期(7-8月)稠糊带末并引入蛋黄、肉泥；细碎期(8-10月)碎末小块并引入手指食物；咀嚼期(10-12月)小块软食；幼儿期逐步接近家常饮食。

## 维护与同步

1. `data/recipes.json` 是**唯一数据源**。新增/修改食谱请编辑生成脚本 `data/_gen_recipes.js` 后运行 `node data/_gen_recipes.js` 重新生成，或直接编辑 `data/recipes.json`（须保持 JSON 合法且字段完整）。
2. 修改后**必须同步**到云函数打包副本 `cloudfunctions/initRecipes/recipes.json`（两份内容需完全一致）：

   ```bash
   npm run sync:recipes   # 将 data/recipes.json 复制到 cloudfunctions/initRecipes/recipes.json
   ```

3. 同步后在微信开发者工具中**重新上传部署** `cloudfunctions/initRecipes`，再调用导入（见项目根 `README.md`「云开发初始化」章节）。
4. `tests/recipes.test.js`（jest）会校验数据结构与两份文件一致性，提交前请运行 `npm test` 确保全绿。

> JSON 不支持注释，故数据源 `recipes.json` 中不含任何说明文字，所有说明集中于本文件。
